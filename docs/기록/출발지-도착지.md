# 출발지·도착지 좌표 메모

> **성격**: 초기 설계 단계에서 남긴 좌표 메모입니다.
> ⚠️ **여기 적힌 '출발지'는 현재 코드가 쓰지 않습니다** — 아래 3장을 보세요.
> 지금 쓰는 값의 정본은 [`project_config.py`](../../project_config.py)의 `DEPOT_*` 상수이고,
> 운용 모델은 [FLEET.md](../구현/FLEET.md)에 있습니다.

---

## 1. 좌표

| 구분 | 이름 | 위도 | 경도 |
| --- | --- | --- | --- |
| 출발지 | 대전교통공사 | 36.348584 | 127.352746 |
| 도착지 | 타슈 관제센터 | 36.406607 | 127.306457 |

## 2. 당시 코드 형태

지도 설정에서 출발지·도착지를 각각 받도록 해 둔 흔적입니다.

```python
start_name = settings.get('start_name', '출발지(대전교통공사)')
start_lat = float(settings.get('start_lat', 36.348584))
start_lon = float(settings.get('start_lon', 127.352746))
end_name = settings.get('end_name', '도착지(타슈관제센터)')
end_lat = float(settings.get('end_lat', 36.406607))
end_lon = float(settings.get('end_lon', 127.306457))
```

## 3. 지금은 어떻게 되어 있나

**차량은 한 지점(depot)에서 출발합니다.** 출발지와 도착지를 따로 두던 구조는
남아 있지 않습니다.

| 항목 | 현재 |
| --- | --- |
| depot | **타슈 관제센터** (`DEPOT_ID = "ST0001"`) |
| 좌표 | `DEPOT_LAT = 36.406607`, `DEPOT_LON = 127.306457` — 위 '도착지'와 같은 값 |
| 정의 위치 | [`project_config.py`](../../project_config.py) |
| 쓰는 곳 | `pipeline/step2_optimize/vrp.py`(경로 시작점), `pipeline/step3_map/main.py`(지도) |

**대전교통공사 좌표(36.348584, 127.352746)는 코드 어디에서도 쓰이지 않습니다**
(전체 검색으로 확인). 이 문서에만 남아 있는 값입니다.

> 대전교통공사는 좌표가 아니라 **운영 상수의 출처**로 남아 있습니다 —
> 차량 적재 용량 10대가 대전교통공사 확인값입니다
> ([버전관리](버전관리.md) 1.0.1, `project_config.VEHICLE_CAPACITY`).

## 4. 되살릴 일이 생긴다면

출발지와 도착지를 다시 나누려면 세 곳을 함께 봐야 합니다.

- `project_config`에 `DEPOT_*` 대신 `START_*`/`END_*`를 두고, **한 곳에서만** 정의할 것
  (지금 depot 상수는 step2·step3가 공유합니다).
- `vrp.greedy_route()`는 depot 하나를 전제로 씁니다 — 시작점과 종점이 다르면
  중간 복귀 분기의 의미도 달라집니다([FORMULATION.md](../분석/FORMULATION.md) 6장).
- 마지막 depot 복귀가 **애초에 계산에 없다**는 점을 먼저 정리해야 합니다
  ([TODO.md](TODO.md) 1-1).

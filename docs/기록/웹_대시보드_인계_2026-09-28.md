## 3. 정한 것 — 다시 따지지 마라

- **`<select>`를 쓰지 않는다.** 윈도우 크롬은 닫힌 select에서 화살표 키로 `change`를 내서, 바로 이동을 걸면
  화살표 한 번에 화면이 바뀐다(WCAG 3.2.2). 대신 **`<details>` 안의 링크 목록**이다 — 누를 때만 가고,
  스크립트 없이도 열리며, 목록을 묶음(계획 · 실험 · 수집)으로 나눌 수 있다.
- **모양**: 한 줄에 `실행 [2026-09-26 11 · 계획 ▾]`. 누르면 떠 있는 판(`position: absolute`, 본문을 밀지
  않음)에 `전체` → `계획 N개` → `실험 N개` 묶음이 여러 열 격자로 선다. 고른 항목은 파란 바탕(`aria-current`).
- **회차는 목록에 숨기지 않는다** — 늘 넷이라 붙은 단추(`.seg`, 세그먼트)로 다 보이게 둔다. 좁은 화면은 2 × 2.
- **차량**은 작은 고르기 상자(`pick-sm`, 판 폭 24rem, 항목 4.5rem 열).
- 좁은 화면에서 이 고르기들은 더 이상 `m-fold`로 접지 않는다 — 한 줄짜리라 접을 것이 없다.
- 카드 경계: **같은 줄 카드는 바닥을 맞추고**, 그래프 카드는 `subgrid`로 제목·설명·그래프·표 보기 **네 줄의
  높이를 같은 줄 카드끼리 나눠 쓴다.** 늘어난 카드의 남는 자리는 아래에 둔다.
- `/run`의 `.split`은 그대로 둔다(위 표).

## 5. 남은 것 — 이 차례로

1. **`orders.html` 고르기 줄.** 지금의 `<details class="m-fold">` 두 개(계획 고르기 · 차량 고르기)와
   `details.run-more`, 매크로 `run_chip`·`round_row`, `details.run-more` CSS를 걷어내고 한 줄로 바꾼다. 뼈대:

   ```jinja
   {% from "_pick.html" import pick, pick_group %}
   {% if targets or sheet_names | length > 1 %}
   <div class="pickbar no-print">
     {% if targets %}
     {% call pick("run-pick", "실행", run_label, <고른 실행의 종류 이름>) %}
       {% if plan_groups %}{% call pick_group("계획", plan_groups | length) %}
         {% for g in plan_groups %}<a class="pick-item" href="/orders?run_label=…&duration=<g.durations[0].value>" …aria-current>{{ g.run_label }}</a>{% endfor %}
       {% endcall %}{% endif %}
       {% for f in folded_kinds %}{% call pick_group(f.label, f.groups | length) %}…같은 모양…{% endcall %}{% endfor %}
     {% endcall %}
     {% if current_group and current_group.durations %}
     <div class="pick-field"><span class="label">회차</span><div class="seg">
       {% for d in current_group.durations %}<a href="/orders?run_label=…&duration=…" …aria-current>{{ d.label }}</a>{% endfor %}
     </div></div>
     {% endif %}
     {% endif %}
     {% if sheet_names | length > 1 %}
     {% call pick("vehicle-pick", "차량", selected_vehicle or "전체", "" if selected_vehicle else (sheet_names | length) ~ "대", "sm") %}
       <a class="pick-item pick-all" href="{{ 화면 }}?run_label=…&duration=…">전체</a> …V03 V04 …
     {% endcall %}
     {% endif %}
   </div>
   {% endif %}
   ```

   지켜야 할 규칙은 지금 템플릿 주석 그대로다: 실행 링크는 **늘 그 실행의 첫 회차를 함께** 넘기고 차량은 넘기지
   않는다(1.26.262) · 회차 링크는 대조 중이어도 `/orders`로 간다(외부 API는 단추로만) · 차량 링크는 대조 중이면
   `/orders/live`로 간다(`{% set 화면 = … %}`) · 실험은 **지우지 않는다**(1.26.125) · 수집 실행은 '실험' 묶음에
   세우지 않는다(`folded_kinds`가 종류별로 나눠 준다). 고른 실행의 종류 이름은 계획이면 `"계획"`, 아니면
   `folded_kinds`에서 `current_group.kind`의 `label`.
2. **닫기 스크립트**(`base.html`, `data-open-fold` 처리기 근처). 판 밖을 누르면 닫기 · Esc면 닫고 summary로

## 7. 재는 스크립트

서버는 `.\.venv\Scripts\python.exe -m uvicorn webapp.app:app --host 127.0.0.1 --port 8765`로 따로 띄운다
(사용자 서버 8000은 건드리지 않는다). 끌 때는 PowerShell `Stop-Process`(`pbr-run` 2장).

```python
import json, sys
from playwright.sync_api import sync_playwright
BASE = "http://127.0.0.1:8765"
PAGES = ["/", "/run", "/kpi", "/vehicles", "/orders", "/maps", "/data", "/guide", "/collect"]
JS = r"""() => {
  const out = [];
  for (const g of document.querySelectorAll('main *')) {
    if (getComputedStyle(g).display !== 'grid') continue;
    const rows = {};
    for (const k of g.children) {
      if (k.offsetParent === null) continue;
      const r = k.getBoundingClientRect(); (rows[Math.round(r.top)] ||= []).push(Math.round(r.bottom));
    }
    for (const [t, b] of Object.entries(rows))
      if (b.length > 1 && Math.max(...b) - Math.min(...b) > 1)
        out.push({grid: g.className, top: +t, spread: Math.max(...b) - Math.min(...b)});
  }
  const cols = [...document.querySelectorAll('.data-grid .sheet table')].slice(0, 6).map(t =>
    [...t.querySelectorAll('thead th')].map(th => Math.round(th.getBoundingClientRect().left - t.getBoundingClientRect().left)));
  return {grids: out, sheetCols: cols};
}"""
with sync_playwright() as p:
    b = p.chromium.launch()
    for w in (1400, 1920):
        page = b.new_page(viewport={"width": w, "height": 1000})
        for path in PAGES:
            page.goto(BASE + path, wait_until="load"); page.wait_for_timeout(700)
            print(w, path, json.dumps(page.evaluate(JS), ensure_ascii=False))
        page.close()
    b.close()
```

고치기 전(09-26) 출력의 요지가 2절 표다. 고친 뒤에는 `/run`의 `split` 한 줄만 남아야 한다.

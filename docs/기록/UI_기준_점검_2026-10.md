# UI 기준 점검 — 반복 요소를 기준표에 대 보기 (2026-10-10)

기준은 [DESIGN.md 'UI 기준표'](../구현/DESIGN.md#ui-기준표--반복되는-요소의-글자--크기--모서리--여백--상태-2026-10-10)입니다.
여기는 실제 화면이 그 기준과 얼마나 맞는지 잰 기록입니다. **아직 아무것도 고치지 않았습니다.**

## 어떻게 쟀나

- 관제 화면 아홉(`/` · `/run` · `/kpi` · `/vehicles` · `/orders` · `/maps?run_label=2026-09-30 22` · `/data` · `/collect` · `/guide`)과
  현장 앱 넷(`/m` · `/m/route?vehicle=V02` · `/m/progress` · `/m/me`)을 Playwright로 열었습니다.
  관제 화면은 1440px 라이트 · 다크와 390px, 현장 앱은 390px입니다.
- 요소를 역할별 선택자로 모아(글자 20역할 · 조작 21종 · 패널 13종) **계산된 스타일**을 읽었습니다.
  글자 크기 · 굵기 · 줄 높이 · 자간, 모서리 · 그림자 · 테두리 · 안쪽 여백, 높이를 봤습니다. 화면마다 표 창 하나,
  고르기 판 하나, 고정한 풍선 하나를 열어 떠 있는 층까지 쟀습니다(관제 1440px에서 3,396개 요소).
- 상태는 조작 16종에서 쟀습니다. 마우스를 올린 뒤와 키보드 초점(`:focus-visible`) 뒤의 스타일을 쉴 때와 비교했습니다.
  비활성 · 선택됨은 해당 요소를 따로 골랐습니다.
- 스타일 시트의 날값(토큰을 거치지 않은 px)을 셌습니다.
- 스크립트: 세션 임시 폴더의 `ui_audit.py` · `ui_sum.py` · `ui_states2.py`(외부 API 호출 없음). 이 점검을 다시 할 때는
  [pbr-run 스킬](../../.claude/skills/pbr-run/SKILL.md) 4절의 골격으로 같은 선택자를 쓰면 됩니다.

  처음부터 *"조밀한 유틸리티"* 에 준 값이라 기준으로 올렸다.
- **SVG 그래프 눈금(10 · 11px)** 은 viewBox 단위라 화면 크기에 비례한다 — 12px 규칙의 예외로 적었다.

# 한글(HWP)로 옮기기

> 2026-09-18 작성. 원고(`.md`)를 학과 양식의 한글 파일로 옮길 때 할 일이다. **지금은 옮기지 않는다** —
> 원고가 굳을 때까지 `.md`로만 쓴다(README 머리글, 사용자 결정 2026-09-16·09-18).
>
> 근거는 `references/논문양식/`의 학과 양식 한글 파일(`…가이드라인 및 양식(251105).hwp`, 2026-09-18 받음)과
> 김수현 교수 「졸업논문 작성방법」이다. 서식 값은 **한글 파일에서 직접 읽었다**(아래 2-1). 옮길 때는 이 한글 파일을
> 복사해 샘플 내용을 지우고 원고를 채우는 것이 가장 확실하다(6장).

---

## 1. 언제 옮기나

처음 옮기는 것은 다음이 모두 끝난 뒤이다. `.md`가 정본이므로(8장) 그 뒤에 `.md`를 고치면 한글 파일을 다시 만든다.

1. ✅ 게이트 A 재실행 값으로 `<!--A:` 주석을 모두 바꾸고 지웠다(2026-09-21, README 2장).
2. ✅ 5.5~5.8 · 6장 · 8장 나머지 · 9장 · 초록을 썼다(2026-09-20).
3. ✅ 장 파일의 자료 자리(`(자리`)를 모두 그림·표로 바꿨다(2026-09-19, README 4-1).
4. 아래 7장의 **옮기기 전** 점검을 통과했다.
5. 지도교수가 `.md` 원고를 한 번 본 뒤가 좋다 — 옮긴 뒤에 내용을 고치면 `.md`와 한글 두 벌을 손보게 된다(8장).

## 2. 서식

### 2-1. 어떻게 읽었나

학과 양식 한글 파일(HWP 5.0)의 쪽 설정·글자 모양·문단 모양을 문단마다 읽었다(2026-09-18, 일회성 스크립트).
샘플 본문은 스타일을 거의 쓰지 않고 모든 문단이 `바탕글` 스타일에 글자·문단 모양을 직접 입힌 것이어서, 스타일
이름이 아니라 **실제로 입힌 값**을 적는다. 가이드라인 1쪽이 정한 값(신명조 10pt · 줄간격 200% · 양쪽 정렬)과
모두 맞았다.

> PDF로만 볼 때는 한글의 메모 칸이 붙은 채 내보내져 한 쪽이 0.762배로 줄어 있었다. 그때 어림한 값 가운데
> 소절 제목(10pt로 어림 → 실제 11pt 굵게)과 위아래 여백은 틀렸고, 나머지는 맞았다.

## 3. 요소별로 바꾸는 법

| 원고(`.md`) | 한글 |
| --- | --- |
| `# 제1장 서론` | `제 1 장 서 론`. 두 글자 제목은 글자 사이를 띄운다(`서 론`, `결 론`) |
| `## 1.1 …`, `### 2.2.1 …` | 절·소절 제목 스타일 |
| 도입 문단이 없는 장(1·2·5·7·8장은 `## n.1`부터 시작) | 샘플은 장 제목 바로 아래 도입 문단을 둔다. 3·4장은 도입 문단이 있다. 2·5·7·8장은 n.1절(개요·이 장의 성격)이 그 역할을 하므로 그대로 두고, 1장은 서론이라 샘플처럼 바로 본문으로 들어가도 된다 |
| 굵은 글씨 | 원고에는 없다 — 샘플 본문에 굵은 글씨가 없어 2026-09-18에 모두 걷었다(사용자 결정). 한글에서도 굵게는 장·절·소절 제목과 차례의 장 항목에만 쓴다 |
| 문단 첫머리 표제 줄 `1) 이상치`, `0단계 : 수집과 전처리`, 7.4의 `1) 경로 최적성 갭의 정정` | 한 줄로 세우고 다음 줄에 본문. 샘플의 `1) Data cleaning`, `제 1단계 : 평가치 매트릭스의 준비`와 같은 꼴이다 |
| 7장의 가설 `"데이터베이스로 옮기면 빠를 것이다."` | 큰따옴표 그대로. 저자의 주장이 아니라 검증 대상임을 표시한다 |
| 문단 | 첫머리에 공백 두 칸을 넣는다(2-2) |
| 기울임 | 장 원고에는 없고 참고문헌 목록에만 있다. 목록에서는 쓰지 않는다(4-2) |
| `$…$` 문장 속 수식 | 한글 수식(문장 안) |
| `$$ … \tag{3.1} $$` | 한글 수식(가운데) + 오른쪽 번호 `(3.1)` |
| 마크다운 표 + `<표 n-m> 제목` | 한글 표. 제목은 위 가운데, 수치 열은 오른쪽 정렬, `주:` 문단은 표 바로 아래 |
| 이미지 + `[그림 n-m] 제목` | 그림 가운데, 제목은 아래 가운데. 그림 파일은 300dpi로 다시 뽑고 너비는 본문 폭(약 132mm) 이하 |
| 번호 목록 `1.` | `1)` (샘플) |
| 글머리표 `-` | 샘플에 예가 없다. `•` 한 가지로 통일 |
| 인용 `(박정연 외, 2024)` · `박정연 외(2024)는` | 번호로 바꾼다(4장) |
| 유선 문의 `(대전교통공사 … 유선 문의, 2025년 9월 6일)` | 그대로 둔다. 번호를 매기지 않는다 |
| `<표 2-1>`의 띄어쓰기 | 가이드라인 문구는 `<표1-1>`로 붙였고 샘플 차례는 `<표 2-1>`로 띄웠다. 원고처럼 **띄운다**. 붙이라는 지적을 받으면 한꺼번에 바꾼다 |

## 4. 참고문헌 바꾸는 법

가이드라인: 15개 이상, **본문에 인용한 문헌만**, **본문에 인용한 순서대로**, '저자, 논문명, 발행처, 발행연도' 순.

### 4-1. 번호 매기기

1. 제1장부터 부록까지 본문을 순서대로 읽어 각 문헌이 **처음 인용된 순서**로 [1], [2] … 를 매긴다. 옮길 때
   일회성 스크립트로 뽑는다 — 저자-연도 패턴을 [참고문헌.md](참고문헌.md)의 항목과 맞춘다.
2. 같은 문헌을 다시 인용하면 같은 번호를 쓴다.
3. 본문의 모양은 두 가지로 바꾼다. 샘플이 둘을 함께 썼다(`…있다[1].`, `Herlocker et al.(1999)은`).
   - 괄호 인용 `…이다(박정연 외, 2024).` → `…이다[3].` (번호는 마침표 앞)
   - 저자가 주어인 문장 `박정연 외(2024)는` → `박정연 외[3]는`
   - 두 편을 함께 인용하면 `[3][7]`
4. 목록에 번호가 붙은 문헌이 본문에 한 번도 나오지 않으면 뺀다.

### 4-2. 항목 모양

학술지는 `저자, “논문명”, 학술지명, 권(호), pp. 쪽–쪽, 연도.` 꼴로 쓴다. 국외 저자는 샘플처럼 이니셜을 앞에
두고, 마지막 저자 앞에 `and`를 쓴다.

- **기울임은 쓰지 않는다** — 샘플 목록에는 기울임이 없다. 논문명은 큰따옴표로 감싼다.
- **DOI는 뺀다(권장).** 샘플에 없고, 원고 목록 19편 가운데 DOI를 확인한 것이 일부뿐이라 섞으면 항목 모양이
  들쭉날쭉해진다. 기사의 URL은 남긴다(원문을 찾을 다른 길이 없다).
- **자료 출처 네 건**(공공데이터포털, 기상청, 타슈 누리집, TMAP API)은 지금 본문이 인용 표시 없이 이름만
  적는다(<표 4-1>). 가이드라인은 인용한 것만 싣게 하므로, 옮길 때 <표 4-1>의 출처 칸에 번호를 달아 목록에
  올린다. 문헌 19편만으로 15편은 넘으므로 분량 때문에 넣는 것은 아니다.
- 다른 자료의 값을 옮겨 그린 그림(예: [그림 8-1]의 보고서 값)은 캡션 끝에 번호로 출처를 단다.

## 6. 옮기는 방법

**학과 양식 한글 파일을 받았다** (`references/논문양식/…가이드라인 및 양식(251105).hwp`, 2026-09-18). 이 파일을
복사해 가이드라인 1쪽과 샘플 내용을 지우고 원고를 채운다. 그러면 용지·여백·쪽 번호·표지 배치가 그대로 따라온다.
원본은 `.gitignore`가 막으므로(샘플 학생·교수 이름이 들어 있다) 복사본도 저장소 밖이나 논문 폴더 안의 막힌
경로(`*.hwp`)에 둔다.

`.md`가 정본이므로(8장) **옮기기를 여러 번 할 수 있어야 한다.** 손으로 붙여 넣으면 `.md`를 고칠 때마다 한글
파일을 다시 손봐야 한다. 그래서 어느 방법이 되풀이할 수 있는지를 **3장 한 장으로 먼저 시험**해 정한다. 3장은
수식(13개)·표·기호가 가장 많아서 여기서 되면 다른 장도 된다.

| 방법 | 되풀이 | 시험할 것 |
| --- | --- | --- |
| 장별로 붙여 넣고 서식 입히기 | 어렵다 — 고칠 때마다 손으로 | 수식 13개 이상을 한글 수식으로 다시 입력하는 시간 |

## 7. 점검

### 7-1. 옮기기 전 (`.md`에서)

1. `grep -rn "<!--A:" docs/연구/논문/*장_*.md` → 0개. `<!--B:`(게이트 B)는 판정 전이면 3.8절의 하나가 남아도 된다 — 옮길 때 주석만 지운다(README 2장).
2. `grep -n "^(자리" docs/연구/논문/*장_*.md` → 0개
3. 본문이 부르는 그림·표 번호가 모두 있고, 장 안에서 나오는 순서대로 이어지며, **모든 표·그림이 본문에서 한 번 이상 불린다** — 2026-09-22 감사에서 표 열 개(5장 일곱 · 6장 둘 · 8장 하나)가 본문에서 불리지 않고 있었다.
4. 인용한 문헌이 모두 참고문헌에 있고, 목록의 문헌이 모두 본문에 나온다.
5. `python tools/check_consistency.py` → 0건

### 7-2. 옮긴 뒤 (한글에서)

1. **분량** — 서론 첫 쪽부터 결론 끝 쪽까지 30쪽 이상.

4. 참고문헌 번호가 본문 첫 인용 순서와 맞는지, 15개 이상인지.

## 1. 겉표지

샘플의 겉표지와 속표지는 문구가 같다. 속표지는 겉표지를 한 장 더 넣는다.

```text
{제출 연도}년도
학사학위논문

{국문 제목}

{영문 제목}

{제출 연}년 {월}월 {일}일

순천향대학교
SW융합대학
컴퓨터소프트웨어공학과
{이름}
```

- **제목** (2026-09-18, 사용자가 맡겨 정함) — 샘플 제목의 "○○를 이용한 △△ 시스템" 꼴을 따랐다.
  방법(순수요 추정, 군집 기반 최적화)과 대상(대전 타슈)을 제목에 담고, 검증은 초록에서 말한다.
  - 국문: 순수요 추정과 군집 기반 최적화를 이용한 공공자전거 재배치 시스템 — 대전 타슈를 대상으로
  - 영문: A Public Bicycle Rebalancing System Using Net Demand Estimation and Cluster-Based Optimization:
    A Case Study of Daejeon TASHU
  - 표지(21pt)에서는 세 줄로 나눈다: `순수요 추정과 군집 기반 최적화를 이용한` / `공공자전거 재배치 시스템` /
    `— 대전 타슈를 대상으로 —`
- **날짜** — 논문 작성일에 맞추고, 기말고사 기간 사이를 권한다(샘플 메모). 겉표지·속표지·제출서·인준서의
  날짜를 모두 같게 둔다.
- **소속** — 학과 샘플의 표기를 옮겼다. 제출 연도의 단과대학 이름이 같은지 확인한다.
- 2인 팀이면 두 이름을 모두 적는다(샘플 메모). 본 논문은 해당하지 않는다.

# 부록 A 실험 재현 방법

본문의 수치는 아래 스크립트로 다시 계산할 수 있다. 모든 명령은 저장소 최상위에서 가상환경의
Python으로 실행한다. 비용 수치를 다루는 실험은 재고 스냅샷을 인자(`--run-label "2026-08-11 real"`)로
고정해야 본문과 같은 조건이 된다.

<표 A-1> 장별 재현 스크립트

| 장·절 | 내용 | 명령 |
| --- | --- | --- |
| 1.1 | 공식 통계와 공개 대여이력의 같은 주 대조 | `python experiments/diagnostic/survey_crosscheck.py` |
| 1.2 | <그림 1-1> 평일·휴일 순수요 | `python tools/make_thesis_figures.py --only 1-1` |
| 1.3, 8장 | 도크리스 거점 예비 검토 | `python experiments/structure/dockless_hub.py` |
| 2.2.3, 3.7.2 | 그리디 경로와 OR-Tools의 갭 | `python experiments/baseline/ortools_gap.py --period "25년 11월" --limit-sec 10` |
| 2.2.3, 3.7.2 | 난수 씨앗별 갭 | `python experiments/baseline/ortools_gap_seeds.py --seeds "42,7,13" --limit-sec 60` |
| 2.5 | 선행연구 모형의 순수요 적용 비교 | `python experiments/structure/park2024_compare.py` |
| 3.3.4 | 결품 확률 예측 | `python experiments/structure/stockout_forecast.py` |
| 3.5.1, 7.4 | 이동거리 어림 비교 | `python experiments/diagnostic/tour_length_estimate.py` |
| 3.8 | 이동시간 식의 계수 추정 | `python experiments/params/road_time_model.py` |
| 4.1 | <그림 4-1> 파이프라인 구조 | `python tools/make_thesis_figures.py --only 4-1` |
| 4.5 | 차량 결원 시험 | `python experiments/structure/fleet_outage_stress.py --outages 0,1,3,5,7,9 --seeds 42,7,13,21,99` |
| 7.5 | 군집 쪼개기의 미집행 물량 | `python experiments/structure/budget_split.py` |
| 7.5 | 두 군집씩 이어 도는 구조 | `python experiments/structure/multi_cluster_route.py --period "25년 11월" --chain-size 2` |
| 7.5 | 총 대여 기준 충족률 | `python experiments/structure/fulfill_gross.py` |
| 2.6, 7.5 | 12개월 반복 평가와 유의성 검정 | `python experiments/baseline/repeat_eval.py --seeds 42,7,13 --methods P,B0,B1 --day-type weekday` |

도로 이동시간 패널은 `python tools/collect_road_time.py`로 수집하며 API 키가 필요하다.

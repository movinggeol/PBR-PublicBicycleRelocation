# 부록 A 실험 재현 방법

본문의 표와 주요 수치는 <표 A-1>의 스크립트로 다시 계산할 수 있다. 원천 대여이력과 재고 스냅샷, API 키는
공개 저장소에 없으므로 재현하려면 각자 준비해야 한다(4.7절). 명령은 저장소 최상위에서 가상환경의
Python으로 실행한다. 비용 수치를 다루는 실험에는 기준 스냅샷을 `--run-label "2026-08-11 real"`로 준다(환경변수
`PBR_RUN_LABEL`로 받는 스크립트도 있다). 저장된 계획을 읽는 실험에는 기준 스냅샷의 대여소 정보와 재고를 새
라벨로 복사하여 지금의 코드로 다시 세운 계획 `2026-08-11 real raw19`를 준다. 이 계획은 <표 6-3>의 제안 방법과
같다. 이동시간은 식 (3.12)가 기본이고, 상수 속도 가정으로 재려면 환경변수 `PBR_USE_ROAD_MODEL=0`을 준다.
식 (3.12)의 계수는 2026년 9월 15일까지의 표본으로 추정한 값이어서, 그 뒤의 날이 들어가면 조금 달라진다.
그림은 `tools/make_thesis_figures.py --only <번호>`로 그리며, 실험 결과를 담은 [그림 5-1], [그림 6-1], [그림 6-2]는 아래
실험의 산출물을 읽는다. 화면 그림([그림 4-4]~[그림 4-8])은 `tools/capture_thesis_screens.py`로 대시보드를 찍은 것이고,
[그림 4-8]은 타슈 API를 부르므로 `--live`를 줄 때만 찍히며 찍을 때마다 값이 다르다.

# 부록 A 실험 재현 방법

본문의 수치는 아래 스크립트로 다시 계산할 수 있다. 모든 명령은 저장소 최상위에서 가상환경의
Python으로 실행한다. 비용 수치를 다루는 실험은 재고 스냅샷을 인자(`--run-label "2026-08-11 real"`)로
고정해야 본문과 같은 조건이 된다. 이동시간이 결과에 들어가는 값(6.3절의 비용, [그림 3-4]의 시간 열,
7.4절의 운행 시간)은 식 (3.12)를 켜야 하므로 환경변수 `PBR_USE_ROAD_MODEL=1`,
`PBR_ROAD_FIXED_SEC_WEEKDAY=320.4`, `PBR_ROAD_SPEED_KMPH_WEEKDAY=32.11`을 함께 준다. 이 셋이 없으면
상수 속도로 계산되어 소요시간이 본문보다 짧게 나온다.

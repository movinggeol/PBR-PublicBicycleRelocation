## 4-1. 자료 자리 — 아직 만들지 않은 그림·표·그래프 (2026-09-18, 사용자 요청)

그림·표·그래프가 필요한데 아직 만들지 않았으면, 들어갈 자리에 **괄호로 된 한 문단**을 넣어 어떤 자료인지
적는다.

```text
(자리 [그림 3-2] — 선 그래프. 무엇: 가로축·세로축·겹칠 선·표시할 점. 자료: 기간·스냅샷·실험. 캡션(안): …)
(자리 <표 3-3> — 표. 무엇: 행과 열. 자료: …. 캡션(안): …)
```

- 첫머리는 `(자리 [그림` 또는 `(자리 <표`로 고정한다. `grep -n "^(자리" docs/연구/논문/*장_*.md`로 전부
  찾는다(이 README의 예시 두 줄이 걸리지 않게 장 파일만 본다).
- **종류**는 흐름도 · 지도 · 그래프(막대/선/산점도/히스토그램) · 화면 캡처 · 표 가운데 하나로 적는다.
- **자료**에는 어느 기간·스냅샷·실험의 값인지 적는다. 이 문단은 한글로 옮기기 전에 사라지므로 원천 문서의 장
  번호(EXPERIMENTS n장)를 적어도 된다. 게이트 A 재실행 결과로 그릴 것은 문단 끝에 `<!--A:EXP n-->`을 함께 단다.
- **번호**는 이미 있는 그림·표의 번호를 바꾸지 않게 매긴다. 그림 파일(그림1-1·4-1·5-1)과 그림 스크립트가 번호에
  묶여 있어서이다. 앞에 끼워야 하면 그 장의 번호를 한꺼번에 다시 매기고 그림 스크립트와 부록 A도 함께 고친다.
- 만들면 그림 파일을 `초안/그림/`에 두고 이미지 링크와 캡션으로 바꾸고, 본문에 "([그림 n-m])" 참조를 넣고, 부록 A 표에 재현
  명령을 더한다. 필요 없다고 판단하면 지운다.
- **한글로 옮기기 전에 0개여야 한다.**

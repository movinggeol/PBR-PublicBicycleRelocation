## 5. 인용해도 되는 문헌

[초안/참고문헌.md](../초안/참고문헌.md)의 확인 수준을 따른다.

- **본문 확인(📖)** 만 방법·수치의 근거로 쓴다.
- **초록만 확인(📄)** 은 초록이 말한 범위에서만 쓴다 — 이상복 외(2018), 문현수·이영석(2016),
  Ghosh 외(2017), Raviv 외(2013).
- **초록도 못 본 것(◻)과 서지만 본 것(🔖)은 쓰지 않는다** — Chemla 외(2013), Forma 외(2015),
  DeMaio(2009), Vogel 외(2011), 윤영채·조병용(2014). 초안 2장이 Chemla·Forma에 기대던
  문장은 원고에서 뺐다. **원문을 구하면** Forma 외(2015)를 2.2.3에 되살린다(3단계 분해와
  구조가 가장 가깝다).

### 인용 형식

- **APA 7판을 한국어에 맞춘 형식.** 국내 문헌(가나다순) → 국외 문헌(알파벳순) → 자료 출처.
- **유선 문의는 목록에 넣지 않는다**(APA의 개인 교신). 본문에 *(대전교통공사 타슈 관제센터 담당자,
  유선 문의, 2025년 9월 6일)* 처럼 날짜까지 적는다. 학과가 목록 수록을 요구하면 '기타'로 옮긴다.
- **DOI는 원문 PDF에서 확인한 것만 적었다.** 김유신·민지원·이은탁·조근민·지창훈과 국외 5편은
  DOI를 확인하지 않아 비워 두었다 — 지어내지 않는다.
- 끝 쪽수는 PDF에서 확인했다(2026-09-16): 이은탁·손봉수 27–38, 윤은옥 외 83–92, 지창훈 외
  143–156. 문현수·이영석 253–267은 **원문이 아니라 민지원 외(2017)의 참고문헌**에서 확인했다.
- Schuijbroek 외는 로컬 PDF가 2016년 온라인 선공개본이다. 목록은 게재 권호(2017)를 따른다.

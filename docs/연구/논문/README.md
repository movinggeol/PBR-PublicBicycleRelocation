# 졸업논문 원고

> 2026-09-16 시작. [초안/](../초안/)이 **근거를 잃지 않으려고 쓴 작업 문서**라면, 이
> 폴더는 **제출할 문장**이다. 원고는 초안의 사실만 옮기며 새 수치를 만들지 않는다 —
> 수치가 바뀌면 초안(과 그 원천 문서)을 먼저 고치고 여기로 옮긴다.
>
> 최종 제출 형식은 **한글(HWP)** 이다. 학과 양식 파일이 없어 국내 공학 졸업논문의
> 일반 구성으로 쓰고, 양식이 생기면 장 번호·인용 형식만 바꾼다.
>
> **수정은 이 폴더의 `.md`에서만 한다** (사용자 결정, 2026-09-16). `.docx` 변환(pandoc)은
> 원고가 굳을 때까지 보류한다 — 변환본을 먼저 만들면 고칠 곳이 두 벌이 된다.

## 2. 게이트 A 표시 — 09-23 뒤 바꿀 숫자

`scripts/gate_a_rerun.ps1`이 다시 돌리는 실험에서 나온 수치 바로 뒤에 보이지 않는
주석을 단다.

```text
<!--A:EXP 24-->        EXPERIMENTS 24장 재실행 결과로 교체할 것
```

재실행이 끝나면 `grep -rn "<!--A:" docs/연구/논문/` 로 전부 찾아 새 값으로 바꾸고
주석을 지운다. **한글로 옮기기 전에 이 주석이 0개여야 한다.**

## 3. 문체와 표기

| 항목 | 규칙 |
| --- | --- |
| 종결 | `~이다` · `~하였다`(실험·경위) · `~한다`(방법 서술). 구어체(`~했다`·`~다`로 끝나는 짧은 말투) 금지 |
| 강조 | 굵은 글씨는 정의되는 용어가 처음 나올 때만. 이모지·⚠️·🔴 금지 |
| 저장소 흔적 | 문서 링크·파일 경로·스크립트 이름·`(초안 메모)` 금지. 재현 명령은 부록에 모은다 |
| 코드 식별자 | 본문에서는 수식 기호나 우리말로 부른다(`TOP_STATION_LIMIT` → 후보 상한 $N$). 꼭 필요하면 부록 |
| 인용 | 저자-연도: (박정연 외, 2024), (O'Mahony & Shmoys, 2015) |
| 표·그림 | `<표 2-1>` 제목은 표 **위**, `<그림 1-1>` 제목은 그림 **아래** |
| 수식 | 장 단위 번호 (3.1), (3.2) … |
| 수치 | 조건(기간·표본·탐색 시간)을 함께 쓴다. 조건 없는 수치는 싣지 않는다 |
| 날짜 | 본문은 `2025년 10월`, 표 안은 `2025-10` |

## 4. 인용해도 되는 문헌

[초안/참고문헌.md](../초안/참고문헌.md)의 확인 수준을 따른다.

- **본문 확인(📖)** 만 방법·수치의 근거로 쓴다.
- **초록만 확인(📄)** 은 초록이 말한 범위에서만 쓴다 — 이상복 외(2018), 문현수·이영석(2016),
  Ghosh 외(2017), Raviv 외(2013).
- **초록도 못 본 것(◻)과 서지만 본 것(🔖)은 쓰지 않는다** — Chemla 외(2013), Forma 외(2015),
  DeMaio(2009), Vogel 외(2011), 윤영채·조병용(2014). 초안 2장이 Chemla·Forma에 기대던
  문장은 원고에서 뺐다. **원문을 구하면** Forma 외(2015)를 2.2.3에 되살린다(3단계 분해와
  구조가 가장 가깝다).

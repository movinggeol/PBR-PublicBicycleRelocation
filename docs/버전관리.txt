1.2.1 : (2026-08-10) Python 3.14 환경에서 실제 설치·구동 검증 및 그에 따른 수정.
		- 의존성: requirements.txt의 2023년 고정 버전(pandas 2.0.3, numpy 1.24.4 등)이
			Python 3.14의 C 확장 ABI와 맞지 않아 import 단계에서 전부 실패했다.
			3.14 휠이 있는 버전으로 갱신하고 하한(>=) 고정으로 변경.
			(검증 버전: pandas 3.0.5, numpy 2.5.2, scipy 1.18.0, scikit-learn 1.9.0)
		- K-Medoids 교체: scikit-learn-extra는 아카이브된 프로젝트로 Python 3.12+ 휠이 없고
			소스 빌드에 MSVC C++ 빌드툴을 요구해 설치 불가. Rust 구현(FasterPAM)의
			kmedoids 패키지로 교체(API 호환). 합성 데이터로 클러스터링·결정성·수렴 검증.
		- webapp 수정: Starlette 1.x에서 구 TemplateResponse(name, {...}) 시그니처가
			제거되어 전 페이지가 500 오류. TemplateResponse(request, name, {...})로 6곳 수정.
		- 검증 결과: py_compile 27개 통과, 전 모듈 import OK, --dry-run 13단계 exit 0,
			웹 라우트 전부 정상(경로 탈출 차단 확인), 폼 실행→로그→상태추적 동작 확인.
		- 전체 파이프라인 E2E 검증: 타슈 CSV 스키마를 재현한 합성 데이터
			(대여소 90곳, 대여이력 14,000건)로 step0~step2·step4를 전부 실행해 exit 0 확인.
			ILP는 CBC에서 Optimal, step4 평균 개선률 75%, 경로요약 총 192km/최장 95분 산출.
			검증 후 합성 데이터는 실제 파일명을 흉내 내므로 삭제함.
			외부 API 키가 필요한 step0/tashu_api.py와 step3/main.py(TMAP)는 미검증.

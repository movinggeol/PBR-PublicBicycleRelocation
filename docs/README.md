## 문서를 추가할 때

1. **어느 폴더인지 먼저 정합니다** — 읽을 사람이 누구인지로 정합니다(분석가/개발자/심사자/나).
2. **이 목차에 한 줄 추가합니다.** 목차에 없는 문서는 없는 것과 같습니다.
3. **정본을 정합니다.** 다른 문서와 겹치면 한쪽에 몰고 다른 쪽은 링크만 남깁니다.
4. 코드 동작이 바뀌었으면 [기록/버전관리.md](기록/버전관리.md)에 **왜 바꿨는지**를 남깁니다.
